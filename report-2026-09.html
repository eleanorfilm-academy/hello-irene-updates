本月新風格

✍️ 手帳筆記 Notebook：把想法「寫」給觀眾看

這個月帶來的是療癒感最強的一個風格：手帳筆記。一本攤開的方格紙手帳，紙膠帶先壓上、手寫字一塊一塊顯出來、螢光筆掃過關鍵字、紅筆劃掉舊想法。觀眾看的不是字卡，是別人的日記被翻開。一套一樣有三種卡型：

① 文字卡：手寫顯字、紅筆劃掉舊想法、螢光筆掃過重點。最適合「不是Ｘ，是Ｙ」的金句，還有日記感的影片開場。
② 清單卡：方框逐條落筆、綠筆一格一格打勾，重點那條會被螢光筆掃過、紅筆寫小註。行前清單、SOP、「三件事」段落就交給它。
③ 數據卡：手繪圓餅一筆掃出來、數字跳動、紅筆把重點數字圈兩圈。適合「月成績回顧」「成效分享」段落。

這期還多了一個新玩法：「商務色」一鍵切換。把 CONFIG 裡的 theme 換成 "business"，整組配色立刻從手帳暖色變成灰藍低彩度的辦公室感，會議重點、專案清單、月報數據都能直接做成卡，開會簡報感十足。

誰特別適合這個風格？只要你的內容有「記錄、整理、回顧」的味道，手帳就是你的主場：

📹 Vlog 創作者（日常紀錄） 📚 學習型帳號（讀書・語言・考試） 🧁 手作・烘焙・生活風格 📈 IG 經營者（成長覆盤） ✈️ 旅行創作者（行前準備・旅費拆帳） 🏢 企業小編（品牌週報・活動回顧） 🎤 講師・顧問（課後重點・方法論） 🛍️ 電商賣家（檔期成績・上架檢查）

一段 60 秒的口播可以三張混搭：清單卡講準備、數據卡講成果、最後用文字卡收心得，一支有頭有尾的 vlog 骨架就齊了。

跟我這樣說「幫我做一張手帳筆記風格的文字卡，寫『靈感不會來找你，開機了才會』」

拿到 .html 檔後：瀏覽器打開 → 全螢幕 → 螢幕錄影，就能丟進任何剪輯軟體。按 R 重播倒數（倒數數字會寫在紅筆手繪的圈圈裡）、按 S 看音效建議清單、按 O 播離場動畫（整頁會像翻頁一樣翻走喔）。

趨勢角落

📈 本月剪片圈在流行什麼

這個月我幫你看了國外平台圈在忙什麼，挑三件跟你最有關的：

1

YouTube 觀看數改成「一播放就算」，開場 3 秒變得更重要

YouTube 上個月底正式改了規則：8 月 24 日起，不管是 Shorts、長片、Podcast 還是直播，「觀看數」從影片播放的第一幀就開始計算；原本要看滿一段時間才算的觀看，改名叫 engaged view（有效觀看）。官方講得很直接：收益資格、創作者計畫都綁在 engaged view 上。也就是說，總觀看數字會變好看，但真正有意義的，還是「有沒有讓人看下去」。

跟 Irene 這樣說：「幫我做一張開場 3 秒的動態字卡，把這支片最重要的重點釘在畫面上」。開場前 1 到 3 秒能不能抓住人，決定這支片是「路過」還是「看完」。
2

TikTok 八成搜尋發生在「滑到一半」，字幕就是你的關鍵字入口

最新統計指出，84% 的 TikTok 搜尋發生在使用者「已經在滑」的當下，不是打開 App 才去搜；而演算法會直接分析畫面上的字幕和口語內容，來判斷你的影片在講什麼、要不要推進搜尋結果。另外這一年平台持續把流量推給 1 到 3 分鐘、完整看完率高的內容：短片沒有被放棄，但「看完」比「短」更重要。

跟 Irene 這樣說：「幫我用口說剪輯，剪掉贅字和停頓，留下精準的逐字字幕」。字幕乾淨，演算法讀得懂、搜尋帶得出來，完播率也跟著拉高，一次吃到兩種流量。
3

Instagram 官方剪輯 App 上線雙語字幕，一支片直接開兩個語言市場

Instagram 的官方剪輯 App「Edits」在 7 月的更新裡，新增了雙語字幕功能：自動把字幕翻成第二種語言，創作者不用重剪一支片，就能觸及主要市場以外的觀眾。這是接在 6 月「AI 自動偵測口語、把字幕卡在對的時間點」之後的下一步：平台正在把「一支內容、多個語言」變成標配。

跟 Irene 這樣說：「把這支片的字幕翻成英文版」。同一份口說字幕檔多做一份翻譯版，同素材就能分發成兩個語言版本，不用重剪。
怎麼拿到這批更新

跟我說一句：

「幫我更新 Irene」
  1. 用 ZIP 裝的：先回 repo 首頁按 Code → Download ZIP，放到「下載項目」資料夾再說那句話。
  2. 當初用 git 裝的：連下載都不用，直接說那句話。
  3. 更新完開一個新對話就會用到最新版；你的創作者檔案、字幕慣用詞、剪輯偏好一律不動。
